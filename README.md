# QuantWeb

面向真实研究的前端：工作区、策略列表、策略编辑、某策略的回测列表、单次回测结果、模拟历史、因子看板。

```sh
npm ci
npm run check
npm run build
AQ_API_URL=http://127.0.0.1:18846 PAPER_API_URL=http://127.0.0.1:18847 npm run dev
```

默认预览端口为 `41846`，仅监听本机。两个 API 地址需要指向另行配置的服务；本仓不启动后端。未指定 API 时明确显示不可用；可在编辑器编写或导出源码，服务端保存不会假报成功。没有自动连接正式端口或启动正式服务的脚本。

`npm run preview` 体验已构建的 `dist/`；传入相同环境变量。`npm run package` 生成 `.local/packages/quant-web-0.5.2.tgz` 与 SHA256。部署静态资源时需将 `/api` 反向代理至 AQ，`/paper-api` 去掉前缀后代理至 paper；未在本次部署。

现有能力、按钮映射和缺口见 [实现说明](docs/implementation.md)。Python 策略通过取数接口提出证券、字段和历史长度，编辑器明确提交所选日频／分钟、日期和资金，运行后进入真实结果页；无需另填证券池或预热天数。因子计算和历史结果继续采用真实接口。当前未保存源码、名称、日期、资金和运行频率一并保留在原浏览器草稿中，结果返回和刷新恢复同一份编辑。只有主动点击“保存”才写入服务端 Python 文件；历史回测快照只读，不覆盖当前编辑。

设计源保持只读，使用用户提供的 QuantWeb 标志与共享样式；不包含设计稿中的账户快照和演示收益数据。

策略文件及编辑器中的“回测列表”进入 `backtests.html`，按服务端 `strategy_id` 查询。旧单文件继续冻结完整相对路径身份；项目采用系统生成的稳定 `aqproj-…` 身份，改名移动仍关联原回测。纯浏览器单文件草稿仍可回测，但保持未归属。旧未归属记录保留，不按同名策略推断。列表可打开单次结果并返回原策略。真实接口、尚缺字段与验收情况见实现说明和 `design-qa.md`。

文件入口采用服务实际返回的规范路径；大小写或 Unicode 别名不在前端猜测合并。既有别名草稿与规范路径草稿同时存在时保留两份内容，原别名成为同目录可访问的浏览器草稿。旧回测仍按冻结身份精确查询；网络响应不确定时，仅当前内容完全相同才复用幂等编号，不把旧请求恢复到编辑器。

策略运行入口为 `aquant`（例如 `from aquant import *`）；运行模块随 `ashare-quant` 后端安装，不要安装 PyPI 同名第三方包。旧服务端保存策略由后端迁移工具先准备 diff/摘要，停写后统一切换。浏览器草稿按设备/Origin 独立保留：先导出原文，审核导入迁移后再导入与保存，历史源码不改写。见 [接口与实现](docs/implementation.md)。

多文件策略使用普通目录与系统管理的 `aquant.toml`，默认入口 `main.py`；可添加辅助 `.py` 和包目录，推荐项目内相对导入。列表区分分类文件夹、策略项目和单文件策略，项目在现有编辑器左侧显示可折叠文件树；Ace 1.43.3 提供 Python/TOML 高亮。全部未保存文件一同保留和提交，历史查看与代码比较覆盖整个冻结文件集。日期、资金、日/分钟参数继续位于右侧，不写入项目描述。

0.5.0 需与 AQ 0.12.0.dev27 的项目 API 配对；旧单文件、浏览器草稿与冻结历史无迁移改写。首次项目创建才生成目录描述。发布前需备份现有策略目录与浏览器草稿；回退前保留新项目目录，旧前端无法管理新项目。当前工作树完成代码与非浏览器检查；Air 锁屏下未执行浏览器视觉/点击验收，详见 [实现说明](docs/implementation.md)。

0.5.2 与 AQ 0.12.0.dev29 配对：结果页原等待区域显示阶段、实际完成交易日/总交易日、模拟日期、耗时及回测子进程当前/峰值 RSS。准备阶段不造百分比或 ETA；网络中断保留同一任务的上次快照，刷新只读任务状态，终态停止轮询。日志仅打开对应页签时读取。没有新增页面或恢复已删除的“找回原回测”。本次组件与网络/刷新回归通过；Air 锁屏下真实 Chrome 视觉验收尚未完成。
