# 收益概述与派生分析

结果页保留原设计的 20 项指标顺序和“收益概述 / 交易详情 / 每日持仓与收益”层级。日志为次级入口；样式只作用于 `.result-analysis`，不改变其它页面。

完整成交、每日账户/持仓只在选择相应页签时读取；展开策略日志或诊断也会按需读取完整冻结结果。仅查看概述不传输这些原始明细。收益分析响应仍沿用完整 `aq.analysis.v1` 契约，不截断日序列或降低指标精度。

页面区分请求服务、接收响应（实际收到的字节数）与解析阶段，不把代理响应已完成冒充浏览器接收完成。未知或压缩后的总长度不显示虚构百分比。结果相关 GET 每次最多等待60秒，可取消本次读取、重试或返回；这不是回测执行时间或结果大小限制。切换页签、刷新、卸载和离页会中止过期读取，浏览器后退恢复页面时重新读取；不会取消正在执行的回测，也不会修改冻结结果。左上返回当前任务所属策略的回测列表；未记录归属的任务保留 job 上下文，由现有列表流程明确说明。

## 数据接线

结果页先读取任务及已发布结果的摘要身份，随后直接 GET 同一任务 `/result/analysis?analysis_version=returns-v2&benchmark=frozen`。概述不再等待完整 `/result` 响应；因子结果不请求 Python 分析。分析仍由已有后端计算，客户端不另算收益。

结果页接受 `aq.analysis.v1` / `returns-v2` 及明确的比较选择，核对 job_id、源结果摘要、指标单位、有限数值、日序列顺序及采样策略。数据身份或格式不匹配时停止使用派生值，保留冻结汇总，不混用其它任务分析。

接口暂不可用时显示实际错误与重试，也可主动“读取原始冻结汇总”。原冻结汇总与账户点读取成功后仍可展示基础指标与权益曲线，缺少的分析字段保留空值。浏览器不另算风险指标，不用 0 填缺基准、短样本或无平仓交易。

策略回测列表采用后端对同一分析函数的 summary 投影；比较弹窗读取冻结结果与已有 history analysis 接口，复用本模块的身份校验、指标顺序、数值格式和缺失原因。列表保留原 result.snapshot_sha256 供比较校验，analysis_error 独立于结果读取错误。代码比较仅读取 manifest，不触发分析请求。

比较允许运行频率、资金、区间和基准选择等实验输入不同；只有真实的计算口径差异提示相应指标不可直接比较。对其他任务/摘要、不支持版本或无效格式的分析继续拒绝，不以放宽实验变量为由混入错误数据。已有 `/jobs/{id}/analysis` 为后端兼容入口；OpenAPI 中的规范入口为 `/jobs/{id}/result/analysis`，两者返回同一响应。

## 图表和表格

- 三层联动：策略/基准累计收益、每日盈亏、每日买卖成交额。首日之前保留期初资金锚点；1 个月、1 年、全部与日期范围控件使用同一日序列。
- 原最大回撤区间恢复展示；更多分析折叠区包含恢复区间、月度表现、20/60/120 日滚动值。
- 交易表通过订单与成交 ID 关联委托时间和归因结果；原记录没有明确下单类型时留空，不按价格猜市价/限价。
- 每日持仓视图将账户收益与持仓表组织在一起，恢复现金行、未实现盈亏和仓位。现金行不虚构证券浮盈。
- 20 项指标 CSV 与卡片同源，导出原始小数、单位、状态、原因和样本数；百分比单位的小数 0.1 表示 10%。

口径在指标 tooltip 和一行说明中展示：日终评价、年化因子、RF 假设、价格/全收益基准与分红模型。费用已计入权益，显示费用摘要不二次扣除；分红与价差盈亏分别显示。v1 的“超额收益夏普比率”和“信息比率”明确为同口径，不因库同名差异制造不同数值。

## 验证

运行 `npm run check` 与 `npm run package`（含生产构建）。`tests/result-analysis.test.mjs` 验证 20 项顺序、身份/格式拒绝、正确空值、同源导出、仅 GET 接线、订单关联、现金行和范围选择；`tests/comparison-analysis.test.mjs` 验证结果/比较同源、冻结摘要、缺基准/真实0、逐列失败降级、无结果跳过、源码模式不读分析和口径差异提示。

`tests/fixtures/result-analysis.json` 是 AQ `tests/analysis/fixtures.py` 生成的合成契约数据，含正常基准、缺基准、短样本三种场景；不是真实回测或生产示例。浏览器验收应在独立临时预览中使用这些数据，不替换正在运行的结果页或用户历史记录。
