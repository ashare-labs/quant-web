# 使用正式数据回测

按统一部署清单启动 API、worker 和前端，打开 `#/data`。页面先显示当前 profile、正式资产与配置身份；未配置时按提示修正清单。

1. 搜索股票代码或名称，勾选需要的证券。可跨搜索结果和分页多选，没有两股样本限制。
2. 选择开始、结束日期和行情来源，点击「读取真实行情」。核对原价、成交量、数据缺口和来源回执；改变选择后旧读取结果及确认会清除。
3. 明确勾选价格诊断限制，再点「发布并打开组合回测」。AD 保留当前窗口、120 个交易日预热、后继交易日和回执；缺数据会清楚拒绝。自动选源固定为用户窗口的实际来源，预热不足不会暗中换源。
4. 组合页显示发布的实际来源与选源窗口。注册策略版本、核对资金和证券，确认回溯状态，点击「检查数据与假设」，接受本次假设后运行价格诊断。结果从任务页查看；刷新页面不会重新提交。

价格诊断采用真实未复权价格，不计公司行动与涨跌停，不是经济总收益或完整可交易收益。发布不会将数据标成公司行动来源覆盖，也不会补造缺失行情。固定日频任务与固定样本行情保留在独立评测入口。

已有草稿不会自动改用第一个数据集。切换环境时保留原草稿并提示；明确选择当前环境的数据窗口，或返回正式数据页重新发布。原策略代码保留。出现响应中断时先核对状态，待确认的回测请求只能重试原参数与原幂等键。

实际可用股票、日期、来源及缺口取决于当前主库。发布后的预检查仍是创建任务的必要条件，行情读取成功不等于回测已通过。
