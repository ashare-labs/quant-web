# 使用正式数据回测

按统一部署清单启动 API、worker 和前端，打开 `#/data`。页面先显示当前 profile、正式资产与配置身份；未配置时按提示修正清单。

1. 搜索股票代码或名称，勾选需要的证券。可跨搜索结果和分页多选，没有两股样本限制。
2. 选择开始、结束日期和行情来源，保持默认「普通回测」，核对配置指定的参考数据组，点击「检查普通回测覆盖」。查看逐证券、日期和字段的缺口，以及本次模型假设、来源绑定；可另外「读取真实行情」核对原价、成交量和回执。
3. 覆盖通过后点「发布并打开组合回测」。AD 保留窗口、120 个交易日预热、后继交易日、状态来源、公司行动日程和回执。自动选源固定为用户窗口的实际来源，预热不足不会暗中换源。缺口会阻断发布，不会改为诊断或替换证券。
4. 组合页显示发布来源与数据声明模式。注册策略版本、核对资金和证券，确认回溯状态，点击「检查数据与假设」，接受本次精确假设后运行回测。结果从任务页查看；刷新页面不会重新提交。更换证券、日期、模式或环境后须重新检查。

普通回测使用所选窗口的价格、状态和公司行动来源。已知停牌由执行模型处理；现金及股份按声明日期模型入账，现金采用来源声明的税前模型。来源覆盖不等于历史当时可见、实际可成交或全市场行动完整性认证，以本次回执限制为准。

新任务初始仅现金，不继承窗口前持仓或待收权益；预热数据不形成持仓。登记日在起点前的行动不产生本账户权益，公司行动来源日程仍保留。组合精确预检会明确展示这条账户规则及后端确认的相关事件日期，沿用本次假设确认；日期变更后须重新预检。事件列表为空不等于来源中没有公司行动。

需要独立价格研究时，主动将「回测用途」改为「独立价格诊断」，读取行情并勾选限制后发布。它采用真实未复权价格，不计公司行动与涨跌停，不是经济总收益或完整可交易收益。普通覆盖失败不会自动降级；含公司行动日程的数据集不能剥离来源转换成诊断。固定日频任务与固定样本行情保留在独立评测入口。

已有草稿不会自动改用第一个数据集。切换环境时保留原草稿并提示；明确选择当前环境的数据窗口，或返回正式数据页重新发布。原策略代码保留。出现响应中断时先核对状态，待确认的回测请求只能重试原参数与原幂等键。

实际可用股票、日期、来源及缺口取决于主库与所选参考组的共同覆盖。没有默认参考组时须明确选择已配置组或修正部署清单；不会自动选择第一个。发布后的精确预检仍是创建任务的必要条件，行情读取或覆盖检查成功都不等于回测已完成。

配置中的「正式发布参考数据」组直接使用与价格相同的正式发布，自动覆盖该发布已具备证据的
股票和日期。它会显示「回溯日状态」「来源记录限价」假设；旧静态参考组仍可供已有窗口对照。
公司行动为空只表示已采来源台账在这个窗口没有记录，不代表已证明所有行动类型完整或历史
当时可知。缺证提示仍需按具体证券、日期、字段处理，页面不会用价格诊断替代普通回测。

默认入口是“组合回测与策略”。先新建或选择策略，选择内置组合算法并注册版本，在策略工作台配置数据窗口、证券和日期，再检查假设并运行。已有数据窗口可以复用；需要其他股票或日期时，点击“准备或更换回测数据”，复用本页准备并检查后返回策略工作台。数据准备入口保留在功能导航最后，不新增另一套回测流程。
