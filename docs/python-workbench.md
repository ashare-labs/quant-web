# Python 策略工作台

打开 `#/workbench`，载入可编辑 Python 示例或导入自己的 `.py`。填写股票池、日期、资金和参数，确认可信代码与研究模型，然后选择“准备数据并回测”。系统冻结正式行情与参考资料；不用先去数据页发布。编辑器草稿自动保存在当前浏览器，可下载源码；已提交任务始终使用提交时的代码。

提交后页面定位到进度，分别显示排队、准备数据和运行策略。可取消计算；离开或刷新页面只恢复状态，不重跑。网络提交结果未知时，“确认原请求”只重试已保存的原参数和幂等键。若环境变了会明确停止，不把旧请求自动投到新环境。取消或中断的 Python 内存不做续跑，修改后再次运行会创建独立的新任务。

结果包括区间收益、期末权益、日末最大回撤、账户曲线、成交明细、委托原因和策略日志，可下载。失败结果显示原生错误和源码位置，缺口保留具体证券/日期/字段，不以零补齐。页面不会推算未经支持的年化或夏普。

本入口使用现有分钟引擎：initialize、handle_data、run_daily，支持已可见分钟历史、股票池内动态选股和委托。参数在 context.parameters，股票池在 context.securities；原价历史查询使用 fq=None。当前本机预算为最多 8 股、23 交易日和 20,000 根股票分钟线，需有完整时段、必要状态与公司行动资料，且策略在结束前自行平仓。不能访问未准备的股票、未来数据、财务 API 或全市场动态股票池。

模型使用来源标签作收盘解释、日状态回放、下一分钟开盘撮合、T+1、5%/10% 日线前收限价与来源范围公司行动。它不是完整历史 PIT 或交易所规则认证。可信代码运行在有网络和资源限制的独立进程中；这不是恶意代码沙箱。

日频七种算法在“日频示例”，固定窗口日频任务保留原入口；这些与分钟 Python 能力不同。数据诊断、固定样本和内部执行演练收在“高级工具”。本次开发只交付隔离候选，不代表正式服务已经更新。
