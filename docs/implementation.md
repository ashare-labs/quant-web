## 明确缺口

- PythonCreate 仍要求外部 `securities`，尚不支持从 Python 取数接口声明证券/字段。本版“开始回测”保持不可用，不发送默认两股、旧 JSON、源码模板或隐式同意。配置只有起止日期和初始资金。服务端支持日频/分钟执行本身不等于这个交互契约已满足。
- 服务端文件接口只存 Python 源码，不存日期/资金/频率，不提供重命名、策略删除或版本系统。目录响应没有修改时间，列表相应显示“—”，不借用浏览器时间冒充文件时间。
- paper 创建/推进/暂停/恢复已退役，页面不把本地记录冒充运行中的模拟交易。
- 指数历史成分池、稿件里的组合回测/交易过滤/预计算全目录 IC 排名无对应接口。不复制稿件的历史账户数据；列表 IC/IR 不伪造，所选真实任务的统计评价可读。
- 任意 Python 内存不能断点续跑；无假恢复按钮。状态优先使用 display_status；retired/runtime_unavailable 不展示为等待运行。
- 普通结果使用当前可见表 CSV；原服务响应只在“诊断 JSON”导出，不另造普通 JSON 格式。基准收益、Alpha、Beta、Sharpe 未提供时为“—”，不能记零。

## 实现边界

六页采用同一 React/TypeScript 入口和共用样式，产物为六个独立 HTML 入口及静态资源。不保留旧演练平台页面、七策略注册和旧 portfolio/daily API。后端实现不在本仓修改范围。

策略列表按设计稿显示“全部文件”目录提示与五列表格；文件夹使用同一张表，进入目录后可通过“全部文件”返回。目录从服务读取；旧浏览器文件夹及尚未落盘的草稿仍可访问，读取不会迁移、合并或删除记录。旧草稿沿用同一表格，名称后注明“浏览器草稿”。没有“历史回测”“历史策略”分类、专属列表请求或历史策略版本编辑入口。表格中设计稿原有的“历史编译运行”“历史回测”列保留，没有记录时显示“—”。列表不再请求历史任务/策略集合，也不将历史名称纳入新文件命名。独立结果页及其查看源码入口继续使用通用任务详情、结果、日志和 manifest 读取。

完整契约仍对应实际 AQ 后端。通用历史读取也供 CLI 与冻结证据读取使用，不是列表分类的专属后端模块，本次未删除这些接口或任何真实记录。

策略编辑只保留左侧“保存”：源码写入本机服务的 strategies 目录，日期/资金/频率等配置留在现有浏览器草稿记录中。草稿允许暂缺日期或资金；已填值仍检查日期合法性、上海时间的今天上限、起止顺序，以及资金大于 0 且不超过 1 亿元。原生日历、手工输入、保存与完整配置校验共用日期规则。今天可选只代表日期合法，不代表当天行情完整或已有数据。

新建策略默认初始资金为人民币 100,000，日期不预填；已存草稿（包括空白金额）原样读取。金额输入以逗号分组显示，存储保留未分组的数字文本及小数，完整配置校验返回实际数值。`validateConfig` 保留提交前的完整性检查；开始回测仍因取数契约缺口禁用。

## 文件保存语义

服务端文件以相对路径寻址，编辑器使用 `?file=`；旧 `?draft=` 仍可打开浏览器草稿，`?job=` 继续只读查看冻结源码。已关联服务文件的浏览器记录只恢复日期、资金和运行频率；每次打开必须 GET 文件取得源码，读取失败会报错并禁用保存，不用缓存内容替代。旧草稿仅在用户按下“保存”时创建所需目录并写入该文件，其他草稿和旧文件夹记录保持原样。

新建策略立即 PUT 空 `.py`，`overwrite=false`，同名错误在现有弹窗反馈区显示，不自动覆盖或改名。打开已有文件后保存传 `overwrite=true`；名称改变时以新路径创建，原文件保留，不调用不存在的重命名或删除接口。新建文件夹接 POST，支持在当前目录继续创建子目录；目录导航和刷新使用 GET。

只有 PUT 成功后才更新已保存状态和浏览器配置；保存期间暂时禁用编辑和重复保存。已确认未保存的失败保留编辑内容；网络中断、响应异常或 `STRATEGY_SAVE_UNCERTAIN` 会重新 GET 核对，哪怕读回一致也不冒充刷盘已确认。用户可再次主动保存；不自动重试写入。源码成功但浏览器配置保存失败时明确区分两者。保存不会执行代码、提交回测、修改冻结结果或隐式生成配置旁车文件。

已用该契约对应后端的隔离部署验证目录、新建/覆盖、重新读取、服务重启后的内容保留；浏览器还验证同名拒绝、写入失败、不确定响应读回、配置存储失败、旧草稿和布局保持。真实部署与 41846 未切换，后续需父任务统一联验。

## 运行频率

编辑器按原设计在初始资金之后、Python3 标记之前恢复原生选择框，选项顺序和文案为“分钟”“日”，对应 `1m`、`1d`。原稿默认选中首项分钟；新建及没有频率字段的旧草稿因此采用可见的 `1m` 默认，已存选择不覆盖，不根据源码或文件名猜测运行模式。控件采用原稿的 66 × 44 尺寸和共享边框/字体样式，保留既有日期/资金标签及响应式换行；未重新设计工具栏。

频率写入现有浏览器 `Draft.frequency`，和日期/资金一起由唯一“保存”入口持久化。打开旧草稿不会自动回写；正常保存时写入显式值，保存失败保留本次选择和原存储记录。历史只读页使用 manifest.request.frequency，缺失则显示“未记录”，不套用新建默认值。

提交适配应使用 `src/shared/drafts.ts` 的 `pythonBacktestConfig(draft)`：验证完整日期、资金和频率，返回类型化 `{start_date, end_date, initial_cash, frequency}`。`frequency` 永远明确为 `1m` 或 `1d`，不能省略后依赖服务端默认；`initial_cash` 是正确数值。`validateConfig` 仍返回数值资金，保持已有调用兼容。

本次实际浏览器验证切换、保存重读、旧草稿缺省/既存值、失败保存及历史只读；隔离请求捕获验证该配置投影经现有 api helper 序列化后的 POST JSON。没有向真实服务提交任务，“开始回测”仍禁用，完整运行联验由取数接线任务完成。后端 API schema 没有变化。
